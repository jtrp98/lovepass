ทุกเอฟเฟกต์ใหม่ใช้motion-safeและ`prefers-reduced-motion`; ปิดpseudo-element animation/view-transition animationเมื่อreduce; ไม่มีdecorativeloop>5s จึงไม่ต้องเพิ่มpausebuttonให้ทุกการ์ด หากเลือกทำloopภายหลังต้องมีstop/hideตาม2.2.2; หลีกเลี่ยงflash, animateheight/margin/topที่กระทบlayout และงานJSยาวบนmainthread Overlay/confettiไม่เพิ่มขนาดเอกสาร จองพื้นที่success/skeletonก่อนเพื่อไม่เพิ่มCLS แต่ยังต้องวัดCWVจริงหลังทำ
