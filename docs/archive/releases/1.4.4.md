# LOVE PASS 1.4.4

วันที่เตรียม release: 8 พฤศจิกายน 2026 · เปลี่ยนแปลงจาก `1.4.3`

## แก้ไขปัญหาการแสดงผลของขวัญแอนะล็อกบนมือถือ

- **จัดระเบียบ Typography ส่วนหัวแบบเต็มความกว้าง (Full-Width Sequential Layout)**:
  - แก้ไขปัญหาข้อความภาษาไทยแตกแถวเป็นตัวอักษรละบรรทัดบนมือถือ ("ถึง / กอล / ฟ / คน / โปร / ด ♡")
  - นำ `<LoveDoodle />` ออกจากแถว Flexbox ส่วนหัว และให้พื้นที่แนวนอน 100% แก่ข้อความจ่าหน้า ("ถึง {ชื่อ} คนโปรด ♡"), หัวเรื่องของขวัญ และคำสัญญาขีดฆ่าด้วยดินสอ (`~~ให้แค่ปีนี้~~ ตั้งใจทำให้เธอคนเดียว ♡`)
  - ประดับภาพวาดดินสอหัวใจคู่ `illustrations/pencil-hearts.svg` ที่มุมขวาบนของข้อความจ่าหน้าอย่างประณีต
- **Closing Couple Vignette**:
  - ย้าย `<LoveDoodle />` มาจัดวางกึ่งกลางด้านล่างของการ์ด ก่อนถึงคำสัญญาใน footnote พร้อมคุมขนาดคงที่ (`5.5rem`) ให้ปิดท้ายแผ่นกระดาษอย่างอบอุ่นและลงตัว
- **ระยะขอบ Modal & WebKit Compatibility**:
  - เพิ่ม `padding-top` ของ `.gift-keepsake-dialog` เพื่อไม่ให้โบว์ริบบิ้นและเทปวาชิถูกตัดขอบบน
  - เพิ่ม `-webkit-mask` ควบคู่กับ `mask` ใน `.gift-torn-note` และ `.gift-handmade-ticket` เพื่อให้รอยฉีกกระดาษและรอยบากตั๋วแสดงผลคมชัดบน Android Chrome และ iOS Safari
  - ปรับขนาดกริดของตั๋วคูปองให้ยืดหยุ่นบนหน้าจอแคบ (320px–360px)
- **เพิ่มปุ่มปิด `✕` ด้านบนขวา**:
  - เพิ่มปุ่มปิดด้านบนขวาของการ์ด และซ่อนอัตโนมัติใน Clean Screenshot Mode (`is-screenshot-mode`)
- **สมุดตัวอย่างดีไซน์**:
  - เพิ่มส่วน Keepsake Sheet Preview ใน `design/love-pass` ให้ตรวจดูหน้าตาและทดสอบ responsive reflow ได้สะดวก
