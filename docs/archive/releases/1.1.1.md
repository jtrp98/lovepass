# LOVE PASS 1.1.1

วันที่เตรียม release: 30 ตุลาคม 2026 · เปลี่ยนแปลงจาก `1.1.0`

## หน้าแรก

- ตัดส่วน “ตั๋วหนึ่งใบ เดินทางแบบนี้” ที่อธิบายขั้นตอนซ้ำกับตั๋วตัวอย่างที่ลองเล่นได้
- เอาปุ่มสมัครใต้ “บ้านของเรา” ออก เหลือปุ่ม “เริ่มสมุดตั๋วของเรา” ที่หัวหน้าและหลังลองตั๋วจบ
- ย่อป้ายตัวอย่างเป็น “ลองใช้ตั๋วตัวอย่าง · ไม่มีการส่งจริง”
- ลบข้อมูลตัวอย่าง state และ CSS ที่ใช้เฉพาะส่วนที่ตัดออก พร้อมอัปเดตเอกสาร design system

## การอัปเกรด

- ไม่มีการเปลี่ยน API หรือฐานข้อมูลเพิ่มเติมจาก `1.1.0`
- การเตรียม release ใน Git แยกจากการ deploy ระบบออนไลน์ ตาม [release workflow](../../guides/release-workflow.md)

## ผลตรวจ release

- Frontend type check, lint, 7 tests และ production build ผ่านด้วยเลขเวอร์ชัน `1.1.1`
- Backend build และ 52 tests ผ่าน; มี warning เดิม CS8602 และ CS0108 โดย build บนเครื่องใช้ .NET SDK 11 preview และ target .NET 10
- Gmail setup 6 tests ผ่าน
- Playwright บน localhost ผ่านที่ 320, 390, 1280 และ 1440 px ไม่มี horizontal scroll และดูภาพหน้าจอจริงที่ 390/1280 px แล้ว
- ลองเปิดตั๋วและฉีกด้วยคีย์บอร์ด ยืนยันแทนแฟน และเริ่มใหม่ผ่าน ปุ่มสมัครแสดงเพิ่มหลังจบตัวอย่าง ไม่มีการเรียก API หรือ JavaScript page error
- ยังไม่ได้ merge เข้า `main` หรือ deploy เวอร์ชันนี้ออนไลน์
