# LOVE PASS 1.2.1

วันที่เตรียม release: 30 ตุลาคม 2026 · เปลี่ยนแปลงจาก `1.2.0`

## คำขอที่รอแฟนยืนยัน

- แท็บรอยืนยันอ่านคำขอที่ส่งจริงจาก API แสดงโน้ต เวลาส่ง และคูปองเป้าหมายของแต่ละคำขอ
- ไม่มีช่องแก้ไขหรือฉีกส่งใหม่ แม้คูปองชนิดเดียวกันยังมีสิทธิ์พร้อมใช้เหลืออยู่
- รองรับตัวกรองระดับ สถานะว่าง และลองโหลดอีกครั้งเมื่อ API ขัดข้อง

## ซองสิทธิ์ตามระดับ

- ผู้ส่งกำหนดแค่จำนวนใบแต่ละระดับ ไม่ต้องเลือกคูปองหรือกำหนดเพดานซ้ำ
- Backend เตรียมคูปองที่เปิดใช้งานทั้งหมดในแต่ละระดับและบันทึก snapshot ตอนส่ง ผู้รับเลือกหรือสุ่มเอง รวมถึงเลือกแบบเดิมซ้ำได้จนครบสิทธิ์
- ซองที่ส่งแล้วและ client เดิมยังใช้ตัวเลือกและเพดานตามข้อมูลเดิม โหมดเลือกคูปองให้เองยังใช้งานได้
- ไม่มี migration ใหม่ ต้อง deploy API ที่รองรับ `CHOICE` กับ `options: []` ก่อนเปิดใช้ frontend รุ่นนี้

## ผลตรวจ

- Backend build และ 59 tests ผ่าน; Gmail setup 6 tests ผ่านโดยไม่ส่งอีเมล
- Frontend type check, lint, 7 tests และ production build ผ่าน
- Browser suites `test:ui`, `test:pocket`, `test:categories` และ `test:packs` ผ่านบน localhost
- ทดสอบ API/ฐานข้อมูลแยกจริง: ส่งซองด้วยจำนวนสิทธิ์อย่างเดียว ผู้รับเลือก/สุ่มจากคลังคูปองของระดับ รับซ้ำได้ตามสิทธิ์ และผู้ส่งไม่มีสิทธิ์รับแทน
- ตรวจภาพหน้าจัดซองและคำขอรอยืนยันที่ 390/1280 px หลักฐานอยู่ใน `frontend/test-results/` (gitignored)
