# LOVE PASS 1.1.0

วันที่ release: 30 ตุลาคม 2026 · เปลี่ยนแปลงจาก `1.0.0`

## คูปองและพลังพิเศษ

- เพิ่มระดับ **MYTHIC** พร้อมแถบฟอยล์โฮโลแกรมสีพาสเทล และหมวด **GIFT** (ของขวัญ) / **POWER** (พลังพิเศษ) พร้อมภาพประกอบใหม่
- เพิ่มคลังคูปอง 68 แบบตาม [ข้อเสนอคลังคูปอง](../../coupon-library-proposal.md)
- เพิ่มพลัง **EXTEND** ต่ออายุ 60 วัน, **FAST PASS**, **UPGRADE**, **WILDCARD**, **REPLAY** และ **REPLAY GOLD** พร้อมตัวเลือกคูปองเป้าหมายก่อนส่งคำขอ
- ตรวจสิทธิ์และระดับของคูปองเป้าหมาย กันจำนวนไว้ระหว่างรอยืนยัน และคืนสิทธิ์เมื่อปฏิเสธหรือยกเลิก พลังมีผลหลังผู้มอบยืนยันสำเร็จ
- ผู้ดูแลกำหนดพลังและล็อกคูปองจากพลังอื่นได้ คูปองที่ล็อกไว้รับได้เฉพาะการต่อเวลา

## หน้าตาและการใช้งาน

- ปรับหน้าผู้ใช้เป็นธีม Romantic Analog Stationery ใช้ตั๋ว กระดาษ ซอง ตราครั่ง และตรายางร่วมกันทั้งระบบ
- เปิดรายละเอียดด้วยการกางตั๋วในหน้า และส่งคำขอด้วยการฉีกหางตั๋ว พร้อมทางเลือกสำหรับคีย์บอร์ด
- เพิ่มตัวอย่าง dashboard และตั๋วที่ลองใช้งานได้ในหน้าแรก
- เพิ่มชั้นวัสดุ SVG สำหรับเส้นใยกระดาษ เทป ลายตั๋ว แสตมป์ และตราประทับ

## API และฐานข้อมูล

- เพิ่ม `GET /api/v1/coupons/{id}/meta-targets` และข้อมูลพลัง/เป้าหมายในสัญญา API ดูรายละเอียดใน [product spec](../../product/lovepass.md)
- เพิ่ม migration `20261030042214_AddMetaCouponsAndLibrary` สำหรับข้อมูลพลัง คูปองเป้าหมาย และคลังคูปองใหม่
- Migration ข้ามชื่อคูปองที่มีอยู่แล้ว ย้ายรายการในชุดจากต้นแบบเริ่มต้น 7 แบบไปยังแบบทดแทน แล้วปิดการใช้งานต้นแบบเดิม
- คูปองที่มอบไปแล้วอ่านจาก snapshot เดิม และ snapshot ที่ไม่มีข้อมูลพลังยังอ่านเป็นคูปองปกติได้

## การอัปเกรด

- ปล่อย backend พร้อม migration ก่อน frontend ที่ใช้พลังพิเศษ โดย API จะรัน migration อัตโนมัติเมื่อเริ่มระบบ
- การ release ใน Git แยกจากการ deploy ระบบออนไลน์ ตาม [release workflow](../../guides/release-workflow.md) และ [ข้อมูล production](../../guides/online-deployment.md)

## ผลตรวจ release

- Backend build และ 52 tests ผ่าน; build มี warning CS8602 และ CS0108
- Frontend type check, lint, 7 tests และ production build ผ่าน; runtime dependency audit ไม่พบช่องโหว่
- Gmail setup 6 tests ผ่าน
- Playwright: `test:ui` บน production build และ `test:pocket` / `test:categories` บน dev server ผ่าน พร้อมดูภาพหน้าคลังคูปองที่ 390 และ 1280 px
- ปรับ browser test ของหมวดหมู่จาก 7 เป็น 9 หมวด และตรวจ SVG ของ GIFT/POWER
- ยังไม่ได้รัน migration กับฐานข้อมูล production หรือ deploy เวอร์ชันนี้ออนไลน์
