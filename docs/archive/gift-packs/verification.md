## Flow ใหม่ที่พิสูจน์แล้ว

- Migration เพิ่มชุดวันเกิด 22 ใบ พร้อมงานบ้าน 8 ใบ และไม่แสดง Romantic Set
- ซองส่งการ์ดแยกจากซองของขวัญตาม tier การเปิดการ์ดไม่เปิดซอง tier และไม่หักสิทธิ์ในโหมด CHOICE
- ซอง COMMON / RARE / EPIC มีสีต่างกันจาก rarity tokens ตรวจภาพจริงที่กว้าง 390 และ 1280 px
- EPIC 10 ใบ: สุ่ม 4 ใบ แล้วเลือกอีก 6 ใบ ยอด COMMON และ RARE ไม่เปลี่ยน
- เลือกหลายแบบพร้อมกัน เช่น งานบ้าน 2 + กอด 1 แล้วกดรับ 3 ใบในครั้งเดียว
- เลือกและสุ่มหลายใบเป็น transaction เดียว รายการผิดแม้หนึ่งแบบไม่ออกคูปองบางส่วน
- ส่งซ้ำพร้อมกันสร้างเพียงชุดเดียว เปิดชุด FIXED พร้อมกันไม่เพิ่มคูปองซ้ำ คำขอแย่งสิทธิ์ใบสุดท้ายสำเร็จเพียงคำขอเดียว
- กรณี API บันทึกผลแล้วแต่ browser ไม่ได้รับคำตอบ ใช้ requestId เดิม retry แล้วได้ผลเดิม ไม่หักสิทธิ์เพิ่ม
- เมื่อแก้ template หลังส่ง ทั้งตัวเลือกในซองและคูปองที่ออกภายหลังยังใช้เงื่อนไข snapshot ตอนส่ง
- ตรวจผู้รับจริง เพดานซ้ำ วันหมดอายุ สิทธิ์ตาม tier และการเลือกจากหน้าเก่า
- failed open ยังปิดซองอยู่ ไม่แสดงผลก่อน API สำเร็จ โหลดใหม่ไม่เล่นเปิด/พลิกผลเก่าซ้ำ
- เลือกด้วยคีย์บอร์ด คืน focus ไปผลที่ได้รับ เคารพ reduced motion และไม่มี horizontal scroll ที่ 320/390/768/1280/1440 px
- ชุดวันเกิดและชุดเลือกตาม tier ผ่านขั้นจัดรายการ → ตรวจการ์ดและของขวัญ → ส่งสำเร็จผ่าน API จริง
